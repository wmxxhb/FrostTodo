# FrostTodo · GPT 风格版

一款参考 Apps SDK UI 设计风格的 Windows 桌面待办应用，支持浅色与深色主题、标签筛选和悬浮收起。

## 功能

- **GPT 风格界面**：中性灰配色、胶囊按钮、矢量图标和统一控件，支持浅色、深色、跟随系统及自选底色。
- **任务管理**：新建时填写主题标签、紧急程度、重要程度、截止日期、提醒和重复规则；支持编辑、完成、删除和撤销。
- **长按排序**：长按任务文字后上下拖动，松开自动保存顺序；支持边缘自动滚动、撤销和筛选视图内排序。
- **标签筛选**：快速查看所有任务、今日任务、已完成任务；可选展示紧急、非常紧急、重要、非常重要和自定义标签，顶栏支持横向滚动及拖动。
- **组合筛选**：按主题、紧急程度和重要程度组合筛选任务。
- **磨砂外观**：调节磨砂不透明度，独立选择底色与字体颜色，使用默认色板、调色盘或撞色搭配。
- **图片背景**：导入、更换或移除 JPG、PNG、BMP 图片。图片居中铺满并保持模糊，自身透明度固定，滑块只改变上层磨砂的浓淡。
- **字体调整**：选择字体、字号、常规至加粗字重、任务标题字间距、任务信息行距、辅助文字浓度和文字显示方式，支持实时预览、清晰推荐及恢复默认。
- **窗口模式**：保持置顶、普通窗口、保持置底；窗口位置和大小自动保存。
- **便捷收起**：收起为悬浮小点或完全隐藏；悬浮点可显示所有待办、今日待办等计数。
- **本地保存**：任务与设置保存在电脑上，支持导出备份和导入任务，无需账号。

## 使用指南

### 启动

适用于 64 位 Windows 10 / 11，需要 .NET Framework 4.8。

1. 在 [Releases](https://github.com/wmxxhb/FrostTodo/releases/tag/v0.4.0-gpt.1) 下载 `FrostTodo-GPT-Windows-0.4.0-gpt.1.zip`。
2. 完整解压，保留 `Fonts` 文件夹和 `FrostTodo-GPT.exe.config`。
3. 双击 `FrostTodo-GPT.exe` 启动。

这是独立版本，不会覆盖磨砂版。首次启动会将原版已有任务、标签和顶栏选择复制到 GPT 版；之后两版各自保存，不会互相覆盖。

更新 GPT 版时先从系统托盘菜单退出它，再运行新版。仅收起窗口不会退出应用。

### 新建、编辑与完成任务

- 点击右上角的 **＋** 新建任务，填写标题后即可创建，其余选项按需填写。
- 点击任务文字进行编辑，点击任务前的圆圈完成；再次点击可恢复。
- 在编辑页可删除任务。完成或删除后，可在短时间内点击“撤销”。
- 长按任务文字约半秒，任务变淡后上下拖动，按插入线选择位置，松开保存。短按仍然编辑，任务前的圆圈仍用于完成任务。
- 拖动到列表上、下边缘可自动滚动；按 `Esc` 或在列表外松开可取消。排序后可点击“撤销”。
- 筛选状态下只调整当前可见任务，隐藏任务的位置保持不变；顺序自动保存，重启后仍然保留。
- 设置重复规则后，完成任务会进入下一次待办日期。
- 日期框中的 **×** 可清除日期；时间选项可选择、输入或清除。

### 重复任务与提醒

- 每日重复任务会在对应日期进入“今日任务”，无需填写截止日期；悬浮点的今日计数与列表一致。
- 未指定日期时，从创建当天开始。设置了将来的下次日期或首次提醒日期，会从指定日期开始。
- 工作日按周一至周五安排，每周按首次日期对应的星期安排，自定义重复只在选中的星期出现。
- 每月重复保留原定日期；例如每月 31 日，在 2 月安排到月底，之后仍回到 31 日。
- 本次完成后进入下个周期，当天不会重新出现。启动或跨天后会跳过错过的旧周期，显示当前或下次任务；普通一次性任务仍保留逾期状态。
- 重复任务可单独设置时间，不必强制填写截止日期；需要通知时，另外设置提醒日期与提醒时间。
- 重复提醒会随周期推进；点击“稍后 10 分钟”只延后本次通知，不改变以后重复提醒的时间。
- 已经响过的提醒不影响修改任务标题；跨天编辑时，未修改的日期和提醒会保留最新状态。

### 筛选与标签

- 点击顶栏标签切换任务视图。标签较多时，可左右拖动、滚动或使用触控板横向滑动。
- 点击右上角的筛选图标，组合选择主题、紧急程度和重要程度。同一维度满足任一条件，不同维度需要同时满足。
- 在 **功能设置 → 标签管理** 添加、删除标签，并选择是否在顶栏展示。
- 所有任务、今日任务、已完成固定展示；其余入口均可选择显示或隐藏。
- 删除标签只移除分类，不会删除任务。

### 调整外观与字体

点击右上角的调色盘图标，打开 **外观设置**。

- **界面主题**：可选浅色、深色、跟随系统或自选底色；默认使用纯白背景，深色主题使用中性深灰。
- **字体**：可选系统默认、微软雅黑 UI、Segoe UI、Yozai、霞鹜漫黑和 Cubic 11。
- **字号**：以任务正文字号为基准，范围为 12–22，其余界面文字按比例调整。
- **字重与间距**：选择常规、中等、半粗、加粗，并调节任务标题字间距和任务信息行距。
- **文字清晰度**：调节辅助文字浓度，比较清晰、柔和、跟随系统、像素四种显示方式。可点击“清晰推荐”快速选择一组参数。
- **实时预览**：页面上方固定显示预览；“恢复默认字体设置”只重置字体相关选项。
- **配色与密度**：选择背景底色、字体颜色、撞色搭配和信息密度，也可以使用调色盘自选颜色。
- **背景图片**：点击“导入图片”选择图片，之后可更换或移除。图片会随设置保存，移动原图后仍可使用。
- **磨砂不透明度**：没有图片时调节磨砂背景；有图片时只调节覆盖在图片上方的磨砂层。

### 移动、缩放与收起

- 拖动顶部空白处移动窗口；拖动窗口边缘或右下角手柄调整大小。
- 在 **功能设置 → 窗口模式** 选择保持置顶、普通窗口或保持置底。
- 在 **功能设置 → 收起方式** 选择悬浮小点或完全隐藏。
- 在 **功能设置 → 悬浮点数字** 选择计数范围，也可关闭数字。
- 点击悬浮点展开，拖动悬浮点移动位置，右键可切换计数等选项。
- 完全隐藏后，点击系统托盘图标或使用快捷键唤回。
- 点击收起或关闭窗口后，应用继续留在托盘。需要结束运行时，在托盘菜单或更多菜单中选择“退出”。

### 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + N` | 新建任务 |
| `Ctrl + Enter` | 保存当前编辑的任务 |
| `Esc` | 返回任务列表，或收起主窗口 |
| `Ctrl + Alt + 空格` | 唤回或收起窗口 |

如果全局快捷键被占用，会依次尝试 `Ctrl + Alt + T`、`Ctrl + Shift + F12`；实际生效的快捷键显示在功能设置和托盘菜单中。

### 备份与迁移

- 在 **功能设置 → 导出备份** 保存 JSON 文件，包含任务和设置。
- 在 **功能设置 → 导入备份** 合并任务及标签；不会覆盖当前外观设置。
- 本地数据位于 `%LOCALAPPDATA%\FrostTodo-GPT`。需要完整迁移任务和外观时，先退出应用，再备份或迁移该文件夹。
